# Code of Conduct

We want this project to be a welcoming, harassment-free space for everyone.

**Expected behavior:** be respectful and constructive, assume good intent,
give and accept feedback graciously, and focus on what is best for the
project and community.

**Unacceptable behavior:** harassment, insults, personal attacks, trolling,
publishing others' private information, or any conduct that would be
inappropriate in a professional setting.

Maintainers may edit or remove comments, commits, issues and other
contributions that violate this code, and may temporarily or permanently
ban contributors for behavior they deem inappropriate.

To report a problem, contact the maintainers at **YOUR_EMAIL@example.com**.
All reports will be reviewed and kept confidential.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.
