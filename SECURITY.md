# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's
[private vulnerability reporting](../../security/advisories/new) for this
repository, or email **YOUR_EMAIL@example.com**.

Include steps to reproduce and the impact (for example, a way to make the
tool delete files outside the target directory). You can expect an initial
response within a few days.
